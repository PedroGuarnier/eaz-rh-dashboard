# EAZ RH Dashboard

Dashboard interno para gestão de estagiários do **Escritório de Advocacia Zveiter**, desenvolvido pelo setor de T.I.

## Stack

| Camada | Tecnologia |
|---|---|
| Frontend | HTML + CSS + JavaScript (vanilla) |
| Hospedagem | GitHub Pages |
| Backend / API | Google Apps Script |
| Banco de dados | Google Sheets |

## Funcionalidades

- Visualização de contratos ativos com status por proximidade de vencimento
- Alertas automáticos de contratos vencidos, vencendo em 30 e 90 dias
- Cadastro, edição e remoção de estagiários
- Controle de aditivos contratuais
- Controle de férias e previsão de término de curso
- Distribuição por segmento e instituição de ensino
- Dados persistidos diretamente no Google Sheets

## Como usar

Acesse a URL do GitHub Pages, cole a URL do Apps Script na tela de configuração e clique em **Salvar e Conectar**.
